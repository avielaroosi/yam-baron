# YAM BARON | Hair Studio — דף נחיתה

דף אחד, בלי מערכת ניהול. **תוכן העסק** — טקסטים, מספרי טלפון, כתובת, תמונות וסרטונים — יושב כולו בקובץ אחד: `js/content.js`, וזה הקובץ היחיד שצריך לגעת בו בשינוי תוכן שוטף.
**כותרות המקטעים** ("השירותים", "עבודות", "סרטונים", "יצירת קשר") **וכיתובי הכפתורים** ("לתיאום תור בוואטסאפ", "אינסטגרם") יושבים ישירות ב-`index.html`.

## איך מחליפים תוכן

**טקסטים, מספר וואטסאפ, אינסטגרם, כתובת:** פותחים את `js/content.js` ועורכים את הערכים.
- `whatsapp`: מספר בפורמט בינלאומי, ספרות בלבד, בלי + (למשל `972501234567`).
- `instagram`: שם המשתמש בלי @.
- `phone` ו-`phoneDisplay`: `phone` הוא הספרות בפורמט בינלאומי שמפעילות את כפתור ההתקשרות (`tel:`), ו-`phoneDisplay` הוא המספר כפי שהוא מוצג על המסך (למשל `054-392-2677`). לשנות את שניהם יחד.
- `address`: כתובת מלאה בעברית; כפתור "נווט בוויז" משתמש בה, וכך גם המפה ב"יצירת קשר" — היא Google Maps embed שנגזר מהכתובת הזו, ולכן שינוי כתובת מזיז גם את הסיכה במפה.

**המלצות (צילומי מסך):** שמים את הקבצים ב-`assets/img/testimonials/` ומוסיפים ל-`testimonials` שורה לכל תמונה: `{ src: "assets/img/testimonials/1.jpg", alt: "המלצה של לקוחה" }`. רשימה ריקה = הכיתוב "יעלו בקרוב". לחיצה על תמונה פותחת אותה בגדול. הסרטון (`videos`) יושב באותו מקטע, לצד ההמלצות.

**באנר קופץ (הנחה לתור ראשון):** הבלוק `promo` ב-`content.js`. `enabled: false` מכבה אותו; `delayMs` = אחרי כמה אלפיות שנייה הוא מופיע; הבאנר מופיע בכל ביקור עד שהגולשת לוחצת על כפתור ההטבה (סגירה ב-X מסתירה אותו רק עד הביקור הבא); `hideAfterUseDays` = כמה ימים לא להראות אחרי לחיצה על ההטבה; `whatsappText` = ההודעה שנפתחת בוואטסאפ. לתצוגה מקדימה בכל פעם (גם אחרי שכבר נסגר או נוצל; זה גם מאפס את הזיכרון בדפדפן הזה): להוסיף לכתובת `?promo`, למשל `https://avielaroosi.github.io/yam-baron/?promo`.

**גיפט קארד:** באנר עם תמונה בדף הבית (בין ההמלצות ל"עלינו") וכפתור שפותח חלון קופץ עם הטקסט המלא וכפתור וואטסאפ. הכל ב-`js/content.js` תחת `gift` (`enabled: false` מסתיר את הבאנר והחלון). קישור לשיתוף בסטורי: `https://avielaroosi.github.io/yam-baron/?gift` פותח את דף הבית עם החלון כבר פתוח.

**תיאור שירות:** ב-`services[].desc` אפשר מחרוזת אחת או רשימה של פסקאות, כמו ב"עלינו".

**טקסט "עלינו":** ב-`about.text` אפשר לכתוב מחרוזת אחת או רשימה של מחרוזות; כל פריט ברשימה הופך לפסקה נפרדת.

**החלפת תמונה בלי "תמונה שבורה":** לתת לקובץ החדש שם חדש (למשל `about-4.jpg`) ולהשאיר את הישן בתיקייה עוד יום. דפדפנים שומרים את הדף הישן עד 10 דקות, ואם הקובץ הישן כבר נמחק הם מציגים תמונה שבורה.

**תמונות:** שמים את הקובץ החדש בתיקייה `assets/img/` ומעדכנים את הנתיב ב-`content.js`.
- מומלץ JPEG עד 1600 פיקסל רוחב, עד ~500KB לתמונה.
- פתיח (`hero`): תמונה רוחבית. שירותים/גלריה/עלינו: תמונות לגובה (4:5).
- שימו לב: הנתיבים של `hero.image` ושל `logo.hero` מופיעים גם בשתי שורות `<link rel="preload">` ב-`index.html` (כדי שהפתיח ייטען מהר). אם משנים כאן נתיב — חובה לעדכן גם את שתי השורות האלה.

**לוגו:** הקבצים יושבים בתיקייה `assets/brand/`:
- `logo-full-light.svg` — **הלוגו שמוצג בפתיח.** גרסה וקטורית: חדה בכל גודל, ~42KB במקום 200KB, וכל אות במונוגרמה היא צורה נפרדת (`#mg-y`, `#mg-b`, `#mg-s`) — זה מה שמאפשר לאנימציית הפתיחה להרכיב אותה.
- `logo-full-light.png` — אותו לוגו כתמונה. כבר לא בשימוש בדף, אבל `tools/trace-logo.py` משתמש בו כדי לדעת באיזה מסגור לייצר את ה-SVG, אז **לא למחוק**.
- `logo-full.png` — גרסת טקסט כהה לרקע בהיר. לא בשימוש, שמור למקרה שיידרש.
- `logo-mark.png` — המונוגרמה בלבד (פוטר).
- `logo-original.png` — קובץ המקור של הלקוח, ומקור האמת שממנו נגזר ה-SVG.

הפאביקון הוא `assets/favicon.png` (מונוגרמה, 256×256).

**אם הלקוח מחליף לוגו:** מחליפים את `logo-original.png` (ואת `logo-full-light.png` באותו מסגור), ואז מריצים פעם אחת:

```bash
python3 tools/trace-logo.py
```

הסקריפט מתחקה את הלוגו מחדש ל-SVG. הוא מזהה את שלוש האותיות לפי כך שהן צורות זהב נפרדות שלא נוגעות זו בזו — אם הלוגו החדש בנוי אחרת, צריך לבדוק את הפלט לפני העלאה. דורש `pillow`, `numpy` ו-`scipy`.

**סרטונים:** ברשימה `videos`, כל פריט הוא אחד מ:
- `{ type: "file", src: "assets/video/x.mp4", poster: "assets/img/x.jpg", title: "..." }` — קובץ וידאו אנכי (9:16), מומלץ עד 20MB.
- `{ type: "youtube", src: "https://youtube.com/shorts/XXXX", title: "..." }` — קישור ליוטיוב (גם Shorts).
- `{ type: "instagram", src: "https://www.instagram.com/reel/XXXX/", title: "..." }` — קישור לריל/פוסט.
- `{ type: "placeholder", poster: "assets/img/x.jpg", title: "..." }` — מסגרת זמנית עד שיגיע סרטון.

הסרטונים מוצגים במקטע "סרטונים" כ**מסילה**: כרטיסים אנכיים זה לצד זה מקצה המסך לקצהו. בטלפון מחליקים
באצבע; במחשב גוללים, גוררים בעכבר או לוחצים על החצים. **הסדר ברשימה הוא הסדר על המסך.** שום דבר לא
מתנגן עד שלוחצים, ורק סרטון אחד מתנגן בכל רגע. הכיתוב (`title`) מופיע על הכרטיס, מעל התמונה.

המרת סרטון מהטלפון (‎.mov‎, HEVC, עד 4K) לקובץ שמתאים לאתר: רוחב 720, H.264, ‎2–6MB לסרטון של 15–25 שניות. אין ffmpeg במחשב; הדרך שעבדה (30.09 ו-01.10): `python3 -m venv ffenv && ffenv/bin/pip install imageio-ffmpeg`, למצוא את הקובץ עם `ffenv/bin/python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())"`, ואז `ffmpeg -i in.mov -vf scale=720:-2 -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 96k out.mp4` (`-2` שומר על הפרופורציה של המקור). תמונת פוסטר מאותו כלי: `ffmpeg -ss 5 -i out.mp4 -frames:v 1 -q:v 4 poster.jpg` (‎5 = השנייה שממנה לוקחים את הפריים; לבחור פריים שבו העיניים פקוחות והשיער ברור). שם קובץ חדש לכל סרטון חדש.

**סרטוני רקע (אווירה):** חמישה קליפים קצרים ב-`assets/video/` בשמות `hero-*` ו-`chapter-*`.
הם **קישוט בלבד** — מושתקים, בלופ, בלי קול ובלי כיתוב — ולכן לכל אחד יש תמונת פוסטר שמחזיקה
את הפריים לבדה. דפדפן שמסרב להשמעה אוטומטית, או מבקרת שביקשה פחות תנועה, רואים את הפוסטר
ולא מלבן שחור. הם הונפשו מהתמונות האמיתיות של ים, רק מתמונות שבהן הפנים לא נראות.
הסרטונים שבמסילה (`yam-02.mp4` עד `yam-08.mp4`) הם הצילומים האמיתיים של העבודה, כמו שצולמו; רק קליפי הרקע מונפשים.
**בפתיח יש שני קליפים** — `hero-tall.mp4` (אנכי, 9:16) ו-`hero-wide.mp4` (רוחבי): בנייד הפתיח
הוא `hero-tall.mp4`; מי שהפעיל חיסכון בנתונים רואה את הפוסטר בלבד, בלי שום קליפ נטען.

## אנימציית הפתיחה

בכניסה לאתר המסך שחור, המונוגרמה מתרכבת מהחלקים שלה — ה-Y נכנס משמאל, ה-B מימין, ה-S נשזר ביניהם — ואז הלוגו השלם מחליק בדיוק למקומו בפתיח בזמן שהשחור נמוג וחושף את האתר. סך הכל כ-2.5 שניות.

- **מתנגן פעם אחת בביקור.** מסומן ב-`sessionStorage` (מפתח `yb-intro`), כך שרענון או חזרה לדף לא מנגנים שוב. לראות אותו שוב: לפתוח חלון גלישה פרטית, או לנקות את אחסון האתר בכלי הפיתוח.
- **מכבד `prefers-reduced-motion`.** מי שביקש מהמערכת שלו פחות תנועה לא רואה את הפתיחה בכלל — הדף פשוט נטען.
- **אפשר לדלג** בלחיצה על מקש או על המסך.
- **בלי JavaScript** הפתיחה לא נדרכת מלכתחילה, והדף מוצג רגיל.

הקבצים: `js/intro.js` (הכוריאוגרפיה), הבלוק `intro` ב-`css/style.css` (התזמונים — הם יושבים שם כמשתני CSS, והסקריפט קורא אותם), ושער קצר inline ב-`<head>` של `index.html` שצובע את השחור לפני שהדף נצבע. השער הזה מחזיק גם רשת ביטחון: אם `js/intro.js` לא נטען, השחור נמחק אחרי 3 שניות.

**לכבות את הפתיחה לגמרי:** צריך למחוק מ-`index.html` את **שני** החלקים — גם את שורת `<script src="js/intro.js">` בסוף הקובץ, וגם את בלוק `<style>` + `<script>` של השער ב-`<head>` (מסומן בהערה "שער אנימציית הפתיחה"). למחוק רק את אחד מהם זה תקלה: השער לבדו יצבע מסך שחור לשלוש שניות ואז ייעלם.

## מערכת העיצוב

כל הערכים יושבים כמשתני CSS בראש `css/style.css`, ושינוי שם משנה את כל האתר יחד:
`--ink-*` ו-`--paper-*` (רקעים), `--gold` ו-`--gold-on-paper` (פעולה), `--step-*` (גודלי טיפוס),
`--sp-*` ו-`--section-y` (מרווחים), `--ease` ו-`--dur-*` (תנועה).

**שני כללים שקל לשבור בטעות:**
- **הזהב הוא צבע של פעולה.** כפתור, קישור פעולה, מצב פוקוס. לא מסגרת ולא קו מפריד.
  על רקע קרם חובה `--gold-on-paper` — הזהב הבהיר נותן שם 1.96:1 ולא נקרא.
- **הפרדה בין מקטעים היא החלפת רקע.** שני מקטעים כהים רצופים חייבים שני גוונים שונים
  (`section--dark` ו-`section--ink-1`), אחרת אין ביניהם שום הפרדה.

`cd tools && node check-design.mjs` אוכף את שניהם ועוד: ניגודיות 4.5:1 לכל טקסט,
היעדר צללים ומסגרות, גודל הטיפוס, וידאו שלא מתנגן ב-`prefers-reduced-motion`,
ושהפתיח לא מבקש וידאו בנייד.

## מערכת העיצוב

ה-FAB (כפתור הוואטסאפ הצף) נעלם מול הפתיח ומול יצירת קשר — בשני המקומות האלה כבר יש כפתור
קריאה-לפעולה ראשי משלהם, והכפתור הצף מיותר לידו; הוא מופיע רק במקטעים שביניהם (למשל מול
הגלריה). `cd tools && node check-design.mjs` אוכף את זה, יחד עם יעד מגע של 44px לכל אלמנט
לחיץ בנייד והיעדר גלילה לרוחב ב-390px.

## שכבת התנועה

כל התנועה שתלויה בגלילה יושבת בקובץ אחד, `js/motion.js`, ונשענת על GSAP + ScrollTrigger שנטענים
מ-CDN בשלוש שורות `<script>` בסוף `index.html`. **למחוק את שלוש השורות = אתר סטטי**; הדף שלם גם
בלעדיהן. מי שביקש מהמערכת שלו פחות תנועה (`prefers-reduced-motion`) לא מקבל את השכבה בכלל.

**מה היא עושה:** התוכן של הפתיח נמוג כשגוללים ממנו; תמונות השירותים נחשפות מהצד שלהן וזזות מעט
בתוך המסגרת; קלפי ההמלצות והמפה נכנסים בהדרגה; והגלריה.

**הגלריה:** שתי שורות מקצה המסך לקצהו שנעות בכיוונים מנוגדים. גלילה של הדף מאיצה אותן, גלילה
חזרה הופכת את הכיוון, עכבר מעל שורה מעמיד אותה, ואפשר לגרור אותה (גם באצבע). התמונות רק נוסעות —
בלי הטיה ובלי סיבוב. הכיוונון בראש `js/motion.js`: `DRIFT` (מהירות במנוחה, פיקסלים לשנייה),
`SCROLL_GAIN` ו-`BOOST_MAX` (כמה הגלילה מאיצה). בלי השכבה כל שורה היא פס שגוללים הצידה ביד.
עשר התמונות נשארות עשרה כפתורים; העותקים שהלולאה צריכה נוצרים בזמן ריצה ומוסתרים מקוראי מסך.

## איך רואים את הדף במחשב

```bash
cd yam-baron
python3 tools/serve.py
```
ואז פותחים בדפדפן: http://localhost:8140

**בטלפון, על אותה רשת Wi-Fi:** `python3 tools/serve.py 8141 0.0.0.0`, ובטלפון פותחים `http://<כתובת-המחשב>:8141`
(את הכתובת מקבלים עם `ipconfig getifaddr en0`; היא משתנה מיום ליום).

`tools/serve.py` ולא `python3 -m http.server`, משתי סיבות: הוא אומר לדפדפן לא לשמור קבצים במטמון, כך שרענון
תמיד מראה את המצב הנוכחי (אחרת דפדפן מחזיק קובץ מאתמול שעות); והוא עונה לבקשות חלקיות (byte ranges),
שבלעדיהן Safari באייפון לא מנגן וידאו בכלל.

## בדיקות אוטומטיות

פעם אחת בלבד, בהתקנה ראשונה:

```bash
cd tools
npm install
npx playwright install chromium   # הורדת הדפדפן הסמוי — פעולה חד-פעמית (~100MB), לא צריך לחזור עליה
```

ומכאן והלאה, בכל פעם:

```bash
cd tools
node check-content.mjs   # בודק שהתוכן תקין ושכל התמונות קיימות
node check-page.mjs      # פותח את הדף בדפדפן סמוי, בודק קישורים, ושומר צילומי מסך ב-tools/shots
```
