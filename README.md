# YAM BARON | Hair Studio — דף נחיתה

דף אחד, בלי מערכת ניהול. **תוכן העסק** — טקסטים, מספרי טלפון, כתובת, שעות, תמונות וסרטונים — יושב כולו בקובץ אחד: `js/content.js`, וזה הקובץ היחיד שצריך לגעת בו בשינוי תוכן שוטף.
**כותרות המקטעים** ("השירותים", "עבודות", "סרטונים", "יצירת קשר") **וכיתובי הכפתורים** ("לתיאום תור בוואטסאפ", "אינסטגרם") יושבים ישירות ב-`index.html`.

## איך מחליפים תוכן

**טקסטים, מספר וואטסאפ, אינסטגרם, כתובת, שעות:** פותחים את `js/content.js` ועורכים את הערכים.
- `whatsapp`: מספר בפורמט בינלאומי, ספרות בלבד, בלי + (למשל `972501234567`).
- `instagram`: שם המשתמש בלי @.
- `phone` ו-`phoneDisplay`: `phone` הוא הספרות בפורמט בינלאומי שמפעילות את כפתור ההתקשרות (`tel:`), ו-`phoneDisplay` הוא המספר כפי שהוא מוצג על המסך (למשל `054-392-2677`). לשנות את שניהם יחד.
- `address`: כתובת מלאה בעברית; המפה בדף מתעדכנת לבד לפי הכתובת.

**טקסט "עלינו":** ב-`about.text` אפשר לכתוב מחרוזת אחת או רשימה של מחרוזות; כל פריט ברשימה הופך לפסקה נפרדת.

**תמונות:** שמים את הקובץ החדש בתיקייה `assets/img/` ומעדכנים את הנתיב ב-`content.js`.
- מומלץ JPEG עד 1600 פיקסל רוחב, עד ~500KB לתמונה.
- פתיח (`hero`): תמונה רוחבית. שירותים/גלריה/עלינו: תמונות לגובה (4:5).
- שימו לב: הנתיבים של `hero.image` ושל `logo.hero` מופיעים גם בשתי שורות `<link rel="preload">` ב-`index.html` (כדי שהפתיח ייטען מהר). אם משנים כאן נתיב — חובה לעדכן גם את שתי השורות האלה.

**לוגו:** הקבצים יושבים בתיקייה `assets/brand/` — `logo-full-light.png` (הלוגו המלא בגרסה בהירה, לפתיח הכהה), `logo-full.png` (אותו לוגו בגרסת טקסט כהה, לרקע בהיר — כרגע לא בשימוש באתר, שמור למקרה שיידרש), `logo-mark.png` (המונוגרמה, לפוטר ולפאביקון), ו-`logo-original.png` (קובץ המקור של הלקוח). להחלפה: שמים קובץ חדש עם אותו שם, או משנים את הנתיבים באובייקט `logo` בתוך `content.js`. הפאביקון הוא `assets/favicon.png` (מונוגרמה, 256×256).

**סרטונים:** ברשימה `videos`, כל פריט הוא אחד מ:
- `{ type: "file", src: "assets/video/x.mp4", poster: "assets/img/x.jpg", title: "..." }` — קובץ וידאו אנכי (9:16), מומלץ עד 20MB.
- `{ type: "youtube", src: "https://youtube.com/shorts/XXXX", title: "..." }` — קישור ליוטיוב (גם Shorts).
- `{ type: "instagram", src: "https://www.instagram.com/reel/XXXX/", title: "..." }` — קישור לריל/פוסט.
- `{ type: "placeholder", poster: "assets/img/x.jpg", title: "..." }` — מסגרת זמנית עד שיגיע סרטון.

## איך רואים את הדף במחשב

```bash
cd yam-baron
python3 -m http.server 8080
```
ואז פותחים בדפדפן: http://localhost:8080

## בדיקות אוטומטיות

פעם אחת בלבד, בהתקנה ראשונה:

```bash
cd tools
npm install
npx playwright install chromium   # הורדת הדפדפן הסמוי — פעולה חד-פעמית (~100MB), לא צריך לחזור עליה
```

ומכאן והלאה, בכל פעם:

```bash
cd tools
node check-content.mjs   # בודק שהתוכן תקין ושכל התמונות קיימות
node check-page.mjs      # פותח את הדף בדפדפן סמוי, בודק קישורים, ושומר צילומי מסך ב-tools/shots
```
