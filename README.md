# YAM BARON | Hair Studio — דף נחיתה

דף אחד, בלי מערכת ניהול. **תוכן העסק** — טקסטים, מספרי טלפון, כתובת, שעות, תמונות וסרטונים — יושב כולו בקובץ אחד: `js/content.js`, וזה הקובץ היחיד שצריך לגעת בו בשינוי תוכן שוטף.
**כותרות המקטעים** ("השירותים", "עבודות", "סרטונים", "יצירת קשר") **וכיתובי הכפתורים** ("לתיאום תור בוואטסאפ", "אינסטגרם") יושבים ישירות ב-`index.html`.

## איך מחליפים תוכן

**טקסטים, מספר וואטסאפ, אינסטגרם, כתובת, שעות:** פותחים את `js/content.js` ועורכים את הערכים.
- `whatsapp`: מספר בפורמט בינלאומי, ספרות בלבד, בלי + (למשל `972501234567`).
- `instagram`: שם המשתמש בלי @.
- `phone` ו-`phoneDisplay`: `phone` הוא הספרות בפורמט בינלאומי שמפעילות את כפתור ההתקשרות (`tel:`), ו-`phoneDisplay` הוא המספר כפי שהוא מוצג על המסך (למשל `054-392-2677`). לשנות את שניהם יחד.
- `address`: כתובת מלאה בעברית; כפתור "נווט בוויז" משתמש בה.
- `geo`: קואורדינטות (`lat`, `lon`) למפת וויז המוטמעת. אם הכתובת משתנה: קליק ימני על המקום בגוגל מפות ← העתקת שני המספרים.

**טקסט "עלינו":** ב-`about.text` אפשר לכתוב מחרוזת אחת או רשימה של מחרוזות; כל פריט ברשימה הופך לפסקה נפרדת.

**תמונות:** שמים את הקובץ החדש בתיקייה `assets/img/` ומעדכנים את הנתיב ב-`content.js`.
- מומלץ JPEG עד 1600 פיקסל רוחב, עד ~500KB לתמונה.
- פתיח (`hero`): תמונה רוחבית. שירותים/גלריה/עלינו: תמונות לגובה (4:5).
- שימו לב: הנתיבים של `hero.image` ושל `logo.hero` מופיעים גם בשתי שורות `<link rel="preload">` ב-`index.html` (כדי שהפתיח ייטען מהר). אם משנים כאן נתיב — חובה לעדכן גם את שתי השורות האלה.

**לוגו:** הקבצים יושבים בתיקייה `assets/brand/`:
- `logo-full-light.svg` — **הלוגו שמוצג בפתיח.** גרסה וקטורית: חדה בכל גודל, ~42KB במקום 200KB, וכל אות במונוגרמה היא צורה נפרדת (`#mg-y`, `#mg-b`, `#mg-s`) — זה מה שמאפשר לאנימציית הפתיחה להרכיב אותה.
- `logo-full-light.png` — אותו לוגו כתמונה. כבר לא בשימוש בדף, אבל `tools/trace-logo.py` משתמש בו כדי לדעת באיזה מסגור לייצר את ה-SVG, אז **לא למחוק**.
- `logo-full.png` — גרסת טקסט כהה לרקע בהיר. לא בשימוש, שמור למקרה שיידרש.
- `logo-mark.png` — המונוגרמה בלבד (פוטר).
- `logo-original.png` — קובץ המקור של הלקוח, ומקור האמת שממנו נגזר ה-SVG.

הפאביקון הוא `assets/favicon.png` (מונוגרמה, 256×256).

**אם הלקוח מחליף לוגו:** מחליפים את `logo-original.png` (ואת `logo-full-light.png` באותו מסגור), ואז מריצים פעם אחת:

```bash
python3 tools/trace-logo.py
```

הסקריפט מתחקה את הלוגו מחדש ל-SVG. הוא מזהה את שלוש האותיות לפי כך שהן צורות זהב נפרדות שלא נוגעות זו בזו — אם הלוגו החדש בנוי אחרת, צריך לבדוק את הפלט לפני העלאה. דורש `pillow`, `numpy` ו-`scipy`.

**סרטונים:** ברשימה `videos`, כל פריט הוא אחד מ:
- `{ type: "file", src: "assets/video/x.mp4", poster: "assets/img/x.jpg", title: "..." }` — קובץ וידאו אנכי (9:16), מומלץ עד 20MB.
- `{ type: "youtube", src: "https://youtube.com/shorts/XXXX", title: "..." }` — קישור ליוטיוב (גם Shorts).
- `{ type: "instagram", src: "https://www.instagram.com/reel/XXXX/", title: "..." }` — קישור לריל/פוסט.
- `{ type: "placeholder", poster: "assets/img/x.jpg", title: "..." }` — מסגרת זמנית עד שיגיע סרטון.

## אנימציית הפתיחה

בכניסה לאתר המסך שחור, המונוגרמה מתרכבת מהחלקים שלה — ה-Y נכנס משמאל, ה-B מימין, ה-S נשזר ביניהם — ואז הלוגו השלם מחליק בדיוק למקומו בפתיח בזמן שהשחור נמוג וחושף את האתר. סך הכל כ-2.5 שניות.

- **מתנגן פעם אחת בביקור.** מסומן ב-`sessionStorage` (מפתח `yb-intro`), כך שרענון או חזרה לדף לא מנגנים שוב. לראות אותו שוב: לפתוח חלון גלישה פרטית, או לנקות את אחסון האתר בכלי הפיתוח.
- **מכבד `prefers-reduced-motion`.** מי שביקש מהמערכת שלו פחות תנועה לא רואה את הפתיחה בכלל — הדף פשוט נטען.
- **אפשר לדלג** בלחיצה על מקש או על המסך.
- **בלי JavaScript** הפתיחה לא נדרכת מלכתחילה, והדף מוצג רגיל.

הקבצים: `js/intro.js` (הכוריאוגרפיה), הבלוק `intro` ב-`css/style.css` (התזמונים — הם יושבים שם כמשתני CSS, והסקריפט קורא אותם), ושער קצר inline ב-`<head>` של `index.html` שצובע את השחור לפני שהדף נצבע. השער הזה מחזיק גם רשת ביטחון: אם `js/intro.js` לא נטען, השחור נמחק אחרי 3 שניות.

**לכבות את הפתיחה לגמרי:** צריך למחוק מ-`index.html` את **שני** החלקים — גם את שורת `<script src="js/intro.js">` בסוף הקובץ, וגם את בלוק `<style>` + `<script>` של השער ב-`<head>` (מסומן בהערה "שער אנימציית הפתיחה"). למחוק רק את אחד מהם זה תקלה: השער לבדו יצבע מסך שחור לשלוש שניות ואז ייעלם.

## איך רואים את הדף במחשב

```bash
cd yam-baron
python3 -m http.server 8080
```
ואז פותחים בדפדפן: http://localhost:8080

## בדיקות אוטומטיות

פעם אחת בלבד, בהתקנה ראשונה:

```bash
cd tools
npm install
npx playwright install chromium   # הורדת הדפדפן הסמוי — פעולה חד-פעמית (~100MB), לא צריך לחזור עליה
```

ומכאן והלאה, בכל פעם:

```bash
cd tools
node check-content.mjs   # בודק שהתוכן תקין ושכל התמונות קיימות
node check-page.mjs      # פותח את הדף בדפדפן סמוי, בודק קישורים, ושומר צילומי מסך ב-tools/shots
```
