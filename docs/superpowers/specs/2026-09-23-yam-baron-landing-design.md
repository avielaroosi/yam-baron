# YAM BARON | Hair Studio — דף נחיתה — מסמך עיצוב

תאריך: 2026-09-23
סטטוס: מאושר בשיחה (מבנה הדף + אופן הבנייה + אירוח)

## 1. מטרה

דף נחיתה אחד לעסק עיצוב שיער של לקוחה (ים ברון). ללא תשלומים, ללא טפסים,
ללא מערכת ניהול. כל פעולת המרה = פתיחת שיחת וואטסאפ עם הודעה מוכנה.
קהל: נשים שמגיעות מאינסטגרם בטלפון. לכן: מובייל קודם, טעינה מהירה, כפתור
וואטסאפ תמיד בהישג יד.

## 2. מה לא בונים (YAGNI)

- אין המלצות לקוחות (הוסר על ידי הבעלים).
- אין שירות איפור.
- אין טופס יצירת קשר, אין אימייל, אין תשלומים, אין הזמנת תור.
- אין מסגרת (framework), אין שלב build, אין תלויות npm.
- אין אנליטיקס בשלב זה.
- אין ריבוי שפות: עברית בלבד (השם והתגית באנגלית).

## 3. מראה ותחושה

כיוון: יוקרתי ונקי.

- צבעים: שחור עמוק `#0b0b0b` (רקע ראשי), שמנת `#f3ede4` (קטעים בהירים
  וטקסט על כהה), זהב עדין `#c9a961` (קווים, אייקונים, כפתורים), אפור-חם
  `#a89f91` (טקסט משני).
- גופנים (Google Fonts): `Cormorant Garamond` לשם YAM BARON באנגלית;
  `Frank Ruhl Libre` לכותרות בעברית; `Heebo` לטקסט רץ. לכל גופן fallback
  מערכת.
- הרבה מרווח לבן, תמונות גדולות, קווי זהב דקים כמפרידים.
- `dir="rtl"`, `lang="he"` על המסמך. השם באנגלית מיושר לפי ההקשר.
- אנימציות מינימליות: fade-in עדין בגלילה, מעברי hover על כפתורים.
  מכבדים `prefers-reduced-motion`.

## 4. מבנה הדף (מלמעלה למטה)

1. **פתיח (hero).** תמונה על כל המסך עם שכבת החשכה. השם
   `YAM BARON | Hair Studio`, משפט אחד: "עיצוב שיער · כלות · החלקות",
   כפתור וואטסאפ ראשי. קישור קטן לאינסטגרם.
2. **כפתור וואטסאפ צף.** עגול, ירוק וואטסאפ, בפינה השמאלית-תחתונה, נשאר
   גלוי בכל גלילה (position: fixed). מוסתר כשהפתיח נראה כדי לא להכפיל.
3. **שירותים.** ארבע כרטיסיות: עיצוב כלות, החלקות, תספורות וצבע, תסרוקות
   לאירועים. כל כרטיסייה: תמונה, כותרת, שתי שורות תיאור, קישור וואטסאפ
   עם הודעה מוכנה ספציפית לשירות.
4. **גלריה.** רשת תמונות (2 עמודות בטלפון, 3–4 במחשב). לחיצה פותחת
   lightbox: תמונה מוגדלת, חצים, סגירה ב-Esc / לחיצה בחוץ / החלקה.
5. **סרטונים.** 2–3 סרטונים אנכיים (9:16). כל פריט הוא אחד מ:
   `file` (mp4 מקומי + poster), `youtube` (iframe של Shorts),
   `instagram` (embed רשמי), או `placeholder` (מסגרת עם אייקון נגן, עד
   שיגיע סרטון).
6. **עלינו.** תמונה של ים + פסקה אחת-שתיים.
7. **יצירת קשר.** כפתור וואטסאפ גדול, אינסטגרם, טלפון (קישור tel:),
   כתובת, מפה מוטמעת (Google Maps embed לפי כתובת, ללא מפתח API), שעות
   פעילות.
8. **שורת סיום.** השם, שנה, קרדיט קטן.

## 5. מבנה הפרויקט

```
yam-baron/
  index.html          — שלד הדף. כל הקטעים קיימים, התוכן מוזרק מ-content.js
  css/style.css       — כל העיצוב
  js/content.js       — כל התוכן במקום אחד (window.SITE)
  js/main.js          — רינדור הקטעים מהתוכן, lightbox, וואטסאפ, כפתור צף
  assets/img/         — תמונות (זמניות עכשיו, אמיתיות אחר כך)
  assets/video/       — סרטונים (ריק בשלב זה)
  assets/favicon.svg  — מונוגרם YB בזהב
  README.md           — הוראות בעברית: איך מחליפים תמונות/טקסטים/מספר
  docs/superpowers/   — מסמכי תכנון
```

### 5.1 `js/content.js` — חוזה התוכן

```js
window.SITE = {
  name: "YAM BARON",
  sub: "Hair Studio",
  tagline: "עיצוב שיער · כלות · החלקות",
  whatsapp: "972000000000",        // בינלאומי, ללא + . 000 = מספר דמה
  whatsappDefaultText: "היי, אשמח לשמוע פרטים ולתאם תור",
  instagram: "yambaron.hair",      // handle בלבד
  phoneDisplay: "000-0000000",
  address: "רחוב הדוגמה 1, עיר",   // דמה עד שיתקבל
  hours: [ { days: "א׳–ה׳", time: "09:00–20:00" }, { days: "ו׳", time: "08:00–14:00" } ],
  hero: { image: "assets/img/hero.jpg", alt: "..." },
  services: [ { id, title, desc, image, whatsappText } ],
  gallery: [ { src, alt } ],
  videos: [ { type: "placeholder" | "file" | "youtube" | "instagram", src?, poster?, title } ],
  about: { image, title, text }
};
```

כל מה שמשתנה בין "דמה" ל"אמיתי" חי בקובץ הזה ובתיקיית assets. ה-HTML
וה-CSS לא נוגעים בהם.

### 5.2 `js/main.js` — אחריות

- קורא `window.SITE` ומאכלס את הקטעים (services, gallery, videos, about,
  contact, hours).
- בונה קישורי וואטסאפ: `https://wa.me/<num>?text=<encodeURIComponent>`.
- Lightbox לגלריה (ללא ספריה): פתיחה, חצים, מקלדת, swipe, נעילת גלילה,
  `aria-modal`.
- כפתור צף: מוסתר בזמן שהפתיח בתצוגה (IntersectionObserver).
- Fade-in בגלילה (IntersectionObserver, מכבד reduced-motion).
- סרטונים: רינדור לפי `type`. `instagram` טוען את `embed.js` פעם אחת רק
  אם יש פריט כזה.

## 6. תמונות זמניות

תמונות חופשיות לשימוש מסחרי (Unsplash) של מספרה/תסרוקות/כלה, מורדות
לתיקייה `assets/img` ומוקטנות ל-≤1600px רוחב, JPEG איכות ~80. אם
ההורדה נכשלת: SVG מעוצב בשחור/זהב עם כיתוב "תמונה זמנית". כל התמונות
נטענות `loading="lazy"` חוץ מהפתיח.

## 7. SEO ושיתוף

- `<title>`, `meta description` בעברית, `og:title/description/image`.
- favicon SVG (מונוגרם YB).
- כל תמונה עם `alt`.

## 9. בדיקות (לפני "מוכן")

- צילומי מסך headless ב-390×844 (טלפון) וב-1440×900 (מחשב) של כל הדף;
  בדיקה ויזואלית שאין גלישה אופקית ושהעברית מיושרת.

- הדף נטען ללא שגיאות בקונסול.
- Lighthouse (אם זמין) — יעד: Performance ≥ 90 במובייל.
